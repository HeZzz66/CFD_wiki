        网格生成与质量

        介绍结构化、非结构与混合网格的类型与拓扑，长宽比、偏斜度、正交性等质量指标，边界层网格的首层高度估算，以及网格无关性与 GCI。

        CFD 数值方法基础 · 约 2482 字 · #网格#边界层网格#网格质量#GCI

        网格是离散化的几何载体。同一个格式、同一个物理模型，换一套网格可能得到完全不同的结果：粗网格把激波抹平，扭曲单元让扩散项失真，首层过高使壁面函数失效。因此“会不会画网格”往往比“会不会选格式”更决定一次计算的质量。

        这一页按“类型—质量—边界层—无关性—工具”的顺序展开，最后用一小段 Python 计算结构化网格的单元面积，把几何量与质量指标联系起来。

        网格类型与拓扑

        结构化网格用 \((i,j,k)\) 三重索引标识节点，邻居关系由索引加减一给出。它存储省、寻址快、适合高精度差分与谱方法；缺点是复杂外形需要多块拼接，块与块之间要处理交界面。

        非结构网格用单元与面的连接表存储，单元可以是三角形、四面体、棱柱、金字塔或多面体。它对任意外形适应性强，局部加密方便，是工程 CFD 的主流；代价是内存访问不连续、并行分区复杂、高阶格式难写。

        混合网格在边界层用棱柱（三棱柱）保证法向分辨率，在外场用四面体填充，兼顾贴体与填充效率。笛卡尔网格用规则立方体，配合切单元（cut-cell）贴合边界，生成快、质量好，但小切单元会带来稳定性问题。重叠网格（overset）让多套网格相互重叠，通过插值交换信息，适合运动物体与多体分离，但插值守恒性与 donor 单元选择需要额外处理。

        二维常用单元是三角形与四边形，三维常用四面体、六面体、三棱柱、四棱锥与多面体。单元类型直接影响格式：

        • 四面体对任意几何最灵活，但梯度重构误差大，边界层内很难做到高长宽比；
        • 六面体在主流方向对齐时精度与收敛性最好，但生成困难；
        • 棱柱适合边界层，金字塔用于棱柱与四面体的过渡；
        • 多面体（polyhedral）邻居多、梯度更稳，内存与计算量也更高。

        质量指标

        网格质量没有单一指标，常用以下几个维度。

        长宽比衡量单元在一个方向被拉长的程度：

        \[\mathrm{AR}=\frac{L_{\max}}{L_{\min}},\]

        \(L_{\max},L_{\min}\) 是单元最长与最短特征长度。边界层内长宽比可达几百甚至上千，这是正常的，因为法向梯度远大于流向梯度；但各向同性区域的长宽比应尽量接近 1。

        偏斜度衡量角度偏离正多边形的程度。以四边形为例，可用

        \[S=\max\left( \frac{\theta_{\max}-90^\circ}{90^\circ}, \frac{90^\circ-\theta_{\min}}{90^\circ} \right),\]

        \(\theta_{\max},\theta_{\min}\) 是单元内最大与最小内角。\(S\) 接近 0 表示接近矩形，超过 0.8 通常已算坏单元。偏斜单元会让面法向与中心连线严重不平行，扩散项的非正交修正变大。

        正交性衡量面法向与两侧单元中心连线的夹角：

        \[\cos\theta= \frac{\mathbf{n}_f\cdot\mathbf{d}_{PN}} {\lVert\mathbf{n}_f\rVert\,\lVert\mathbf{d}_{PN}\rVert},\]

        \(\mathbf{n}_f\) 是面法向，\(\mathbf{d}_{PN}\) 是中心连线。\(\theta\) 接近 0 表示正交；超过 60 度后，非正交修正可能超过正交项，解容易振荡。

        Jacobian 与体积。对映射单元，Jacobian 行列式必须为正；为负说明节点顺序反了或单元被压穿，称为负体积。求解器一启动就报负体积，几乎都是网格问题。单元体积还可用散度定理计算：

        \[V_P=\frac{1}{3}\sum_{f\in\mathcal{F}_P} \mathbf{x}_f\cdot\mathbf{n}_f A_f,\]

        \(\mathbf{x}_f\) 是面心位置，\(A_f\) 是面面积。这个式子对任意多面体成立，也是许多求解器检查体积的方式。

        光滑度指相邻单元尺寸的变化率。相邻单元体积突变会带来截断误差的跳变，也会让多重网格与迭代收敛变差。通常希望增长率不超过 1.2 到 1.3。

        坏网格的后果很具体：长宽比过大且法向未对齐，边界层速度剖面出现锯齿；偏斜度过高，压力场出现局部毛刺；负体积直接终止计算；光滑度差，残差曲线反复抬头。与其在求解器里调参数，不如回到网格修单元。

        边界层网格

        壁面附近的法向分辨率用无量纲壁面距离描述：

        \[y^+=\frac{u_\tau y}{\nu}, \qquad u_\tau=\sqrt{\frac{\tau_w}{\rho}},\]

        \(u_\tau\) 是摩擦速度，\(\tau_w\) 是壁面剪应力，\(\nu\) 是运动粘度，\(y\) 是到壁面的距离。\(y^+<1\) 才能解析粘性底层；使用壁面函数时首层通常落在 \(30

        首层高度可以预先估算。对平板湍流边界层，用

        \[C_f=0.058\,Re^{-0.2}, \qquad u_\tau=U_\infty\sqrt{\frac{C_f}{2}},\]

        再取目标 \(y^+\) 得

        \[\Delta y_1=\frac{y^+\nu}{u_\tau}.\]

        例如 \(U_\infty=1\ \mathrm{m/s}\)、\(L=1\ \mathrm{m}\)、\(\nu=1\times10^{-5}\ \mathrm{m^2/s}\)，则 \(Re=10^5\)，\(C_f\approx0.0058\)，\(u_\tau\approx0.054\ \mathrm{m/s}\)。若目标 \(y^+=1\)，首层约 \(1.85\times10^{-4}\ \mathrm{m}\)，即 0.185 mm。

        层数与增长率决定边界层总厚度。若首层 \(\Delta y_1\)、增长率 \(g\)、层数 \(n\)，总厚度为

        \[T=\Delta y_1\frac{g^{n}-1}{g-1}.\]

        常见做法是 \(g=1.1\) 到 \(1.2\)，层数 10 到 30，使总厚度覆盖边界层厚度的 1.5 倍以上。分离区、转捩区、角区需要更细的流向与展向网格，因为那里法向速度剖面变化剧烈，仅靠法向加密不够。

        壁面函数与 y+ 的一致性

        用壁面函数却把首层放在 \(y^+<5\)，或用低雷诺数模型却把首层放在 \(y^+>30\)，都会得到“看起来收敛、实际错误”的结果。换湍流模型时，必须同时检查首层高度。

        网格无关性

        网格无关性指继续加密网格后，关键监测量不再明显变化。做法通常是粗、中、细三套网格，细化因子 \(r\) 约为 1.3 到 2，保持边界层首层与拓扑相似，只改变单元尺寸。

        用 Richardson 外推估计“无限细网格”的值：

        \[f_{\mathrm{ext}}\approx f_1+\frac{f_1-f_2}{r^{p}-1},\]

        \(f_1\) 是细网格解，\(f_2\) 是较粗网格解，\(p\) 是观测到的收敛阶。若三套网格的差值比不符合单调收敛，说明解落在非渐近区，外推不可信。

        工程上常用网格收敛指数（GCI）给出误差带：

        \[\mathrm{GCI}=\frac{F_s\lvert e\rvert}{r^{p}-1}, \qquad e=\frac{f_2-f_1}{f_1},\]

        \(F_s\) 是安全因子，通常取 1.25。GCI 不是严格的误差界，而是一个保守估计：它告诉你能以多快的速度加密网格、当前结果大概在什么误差范围。完整流程与判据见CFD 工作流与验证确认。

        工具只是手段。判断网格好坏的标准与求解器无关：正交、光滑、足够细、边界层匹配。用脚本生成网格时，应该把单元数、最小正交角、最大长宽比、首层 \(y^+\) 作为输出指标，而不是只看“生成了多少单元”。

        结构化网格的 Python 示例

        下面的代码生成一个二维曲线坐标网格，并用对角线叉积计算每个四边形的面积。它演示了两个常被忽略的事实：网格面积不必相等，单元质量可以用面积比快速筛查：

        import numpy as np

nx, ny = 40, 20
xi = np.linspace(0.0, 1.0, nx + 1)
eta = np.linspace(0.0, 1.0, ny + 1)
X, Y = np.meshgrid(xi, eta, indexing="ij")
Y = Y * (1.0 + 0.3 * np.sin(np.pi * X))   # 上边界隆起，制造非均匀单元

# 每个单元的四个角点（逆时针）
p00 = np.stack([X[:-1, :-1], Y[:-1, :-1]], axis=-1)
p10 = np.stack([X[1:, :-1], Y[1:, :-1]], axis=-1)
p11 = np.stack([X[1:, 1:], Y[1:, 1:]], axis=-1)
p01 = np.stack([X[:-1, 1:], Y[:-1, 1:]], axis=-1)

# 四边形面积 = 两条对角线叉积的一半
d1 = p11 - p00
d2 = p01 - p10
area = 0.5 * np.abs(d1[..., 0] * d2[..., 1] - d1[..., 1] * d2[..., 0])

print("单元数：", area.size)
print("总面积：", area.sum())
print("最小面积：", area.min())
print("最大面积：", area.max())
print("面积比：", area.max() / area.min())

        运行后总面积约为 1.191，比未变形时的 1 多出隆起的贡献；最小与最大单元面积之比可以用来判断拉伸是否过强。真实三维网格还应检查每个单元的最小二面角、Jacobian 与相邻体积增长率，这些指标在多数求解器中都有现成报告。

        小结

        • 网格类型决定离散格式的选择空间，结构、非结构、混合、笛卡尔与重叠各有适用场景。
        • 质量指标要一起看：长宽比、偏斜度、正交性、Jacobian、光滑度；任何一项极端都会污染解。
        • 边界层网格的核心是首层 \(y^+\) 与增长率，必须与湍流模型匹配。
        • 网格无关性用三套网格与 GCI 量化，不能凭“看起来差不多”下结论。
