    这是什么

    CFD Wiki 是一个以“可推导、可运行、可工程化”为目标的计算流体力学知识库。它不追求罗列结论，而是尽量把每个结论背后的假设、公式来源和适用边界讲清楚，并给出可以直接改写的代码。

    全站目前分为六章：数学基础、流体力学基本概念、CFD 数值方法、湍流模型、AI for CFD、后处理与工程实践。每一章都可以独立阅读，但整体按“先数学、再物理、后数值与工程”的顺序组织。

    如何使用本站

    1. 按顺序读：第一次系统学习，建议从第一章开始；已经具备场论基础，可以直接进入第二章。
    2. 按问题查：用右上角搜索（Ctrl + K）定位术语，例如 SIMPLE、k-ω SST、FNO、Q 判据。
    3. 按代码改：涉及算法的页面通常同时给出数学表达与 Python / C++ / Fortran 片段，复制后替换参数即可试验。
    阅读约定

    公式中的矢量用粗体或指标记法表示；\(\nabla\) 统一表示笛卡尔坐标下的 Nabla 算子；代码块上方一般会说明依赖库与输入输出。若公式在页面中显示异常，请确认网络可访问 MathJax CDN。

    关于公式与代码

    本站的公式使用 LaTeX 书写，由 MathJax 在浏览器端渲染；代码块由 Pygments 做语法高亮。所有代码都以“说明原理”为首要目标，生产环境使用前仍需要补充边界检查、异常处理与性能优化。

    扩展本站

    本站的导航由文件系统自动生成，新增内容不需要修改生成器：

    • 新增章节：在 content/ 下建立目录，并添加 _chapter.json（标题、副标题、顺序）。
    • 新增页面：在同目录放置 .md 文件，用 front matter 写 title、order、summary、tags。
    • 构建预览：运行 python build.py --serve。

    具体规范见项目根目录的 README.md。
