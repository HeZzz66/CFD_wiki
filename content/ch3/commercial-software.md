网格与格式讲完后，下一步是把它们放进一个能算的软件。商业软件把几何、网格、物理模型、求解与后处理串成一条流水线，开源求解器则把每一步拆成可脚本化的组件。两者不是“好用”与“难用”的区别，而是“谁承担集成成本”的区别。

这一页先给出通用工作流，再逐个说明主流工具的定位，最后讨论选型与常见坑。

## 通用工作流

任何 CFD 软件都绕不开五个阶段。

1. **几何清理**：修复破面、短边、重叠面，删去对流动影响很小的特征（圆角、螺栓孔、薄垫片），确认单位与坐标系。
2. **网格生成**：选择单元类型与边界层策略，控制首层高度、增长率与局部加密，检查负体积与正交性。
3. **物理模型与边界**：选择层流/湍流、可压缩/不可压缩、多相或多组分模型；设置入口、出口、壁面、对称与周期边界。
4. **求解**：选择压力基或密度基、耦合或分离、隐式或显式；设置松弛因子、Courant 数与收敛判据。
5. **后处理**：提取压力云图、速度矢量、流线、等值面、壁面热流，做面积平均、质量流量与时间平均。

这五步中，前两步决定了离散误差，第三步决定了模型误差，第四步决定迭代误差，第五步决定“你看到的是不是你以为的量”。工作流页会展开验证与确认，这里先关注工具差异。

## 主流工具

**Ansys Fluent** 是工程内流与外流最通用的求解器之一。它同时支持压力基与密度基，压力基下有 SIMPLE、SIMPLEC、PISO 与 Coupled 算法，物理模型覆盖湍流、传热、多相、燃烧、动网格与组分输运。优势是模型全、资料多、UDF 与表达式能力强；缺点是历史包袱重，复杂几何的前处理常需借助外部工具。

**Ansys CFX** 以全隐式耦合求解著称，叶轮机械、旋转机械与共轭传热是它的强项。它采用顶点中心有限体积，边界层与周期性交界面处理成熟；界面与 Fluent 不同，学习时需要重新适应。

**STAR-CCM+** 把几何、网格、求解与后处理放在同一个界面，多面体网格与表面重构是招牌能力。它适合汽车、船舶等复杂外形的大规模外流，自动化与参数化扫描做得较好；许可证成本与内存占用较高。

**COMSOL Multiphysics** 基于有限元，强项是多物理场耦合：流固、电磁—热、化学—流动。它允许用户直接输入弱形式，适合研究与教学；纯大雷诺数湍流外流不是它的主战场。

**OpenFOAM** 是开源有限体积工具箱，求解器、边界条件、离散格式都以 C++ 代码与字典文件暴露给用户。优势是免费、可改、可大规模并行、脚本化彻底；缺点是没有统一 GUI，入门需要理解字典结构，遇到问题主要靠社区与源码。

**SU2** 是开源的可压缩流动求解器，面向航空外流与设计优化，内置伴随方法，可做形状优化。它支持非结构网格与多种湍流模型，生态比 OpenFOAM 小，但代码结构清晰，适合学习可压缩算法。

| 软件 | 许可 | 离散方法 | 擅长 | 学习曲线 |
| --- | --- | --- | --- | --- |
| Fluent | 商业 | 有限体积（压力基/密度基） | 通用内流、传热、多相 | 中 |
| CFX | 商业 | 有限体积（耦合、顶点中心） | 叶轮机械、共轭传热 | 中 |
| STAR-CCM+ | 商业 | 有限体积（多面体） | 复杂外流、大规模并行 | 中高 |
| COMSOL | 商业 | 有限元 | 多物理场耦合、弱形式 | 高 |
| OpenFOAM | 开源 | 有限体积 | 定制开发、脚本化、HPC | 高 |
| SU2 | 开源 | 有限体积 | 可压缩外流、伴随优化 | 高 |

## 求解器内部差异

Fluent 的分离式压力基求解沿用 SIMPLE 家族：先由当前压力解动量，再用连续性误差解压力修正，最后修正速度与通量。动量方程的离散形式可写成

$$
\left(a_P+\frac{V_P}{\Delta t}\right)\mathbf{u}_P
=\sum_{nb}a_{nb}\mathbf{u}_{nb}
+V_P\mathbf{S}_u-V_P\nabla p,
$$

$a_P$ 是主对角系数，$a_{nb}$ 是邻居系数，$\mathbf{S}_u$ 是除压力外的源项。耦合式（Coupled）则把动量与连续性放在同一个方程组中同时求解：

$$
\begin{bmatrix}
\mathbf{A}_{uu} & \mathbf{A}_{up}\\
\mathbf{A}_{pu} & \mathbf{A}_{pp}
\end{bmatrix}
\begin{bmatrix}
\delta\mathbf{u}\\
\delta p
\end{bmatrix}
=
\begin{bmatrix}
\mathbf{r}_u\\
\mathbf{r}_p
\end{bmatrix},
$$

$\delta\mathbf{u},\delta p$ 是每步的修正量，$\mathbf{r}_u,\mathbf{r}_p$ 是动量与连续性残差。耦合式收敛更稳，内存也更高，适合强旋转、强浮力与可压缩流动。

CFX 默认采用全隐式耦合，把速度、压力与湍流量的耦合块一起迭代，因此每步都要求解更大的矩阵。STAR-CCM+ 的多面体网格让每个单元拥有更多邻居，梯度与扩散通量的估计更稳，但单元与面的连接表更大，内存开销随之上升。

OpenFOAM 的差异在“配置即代码”。离散格式、线性求解器、松弛因子都写在字典里：

```cpp
// system/fvSchemes：选择离散格式
ddtSchemes
{
    default         steadyState;   // 稳态：去掉时间导数
}
gradSchemes
{
    default         Gauss linear;  // 最小二乘或 Gauss 梯度
}
divSchemes
{
    default         none;
    div(phi,U)      Gauss linearUpwind grad(U);  // 二阶迎风
}
laplacianSchemes
{
    default         Gauss linear corrected;      // 非正交修正
}
```

```cpp
// system/fvSolution：线性求解器与松弛
solvers
{
    p
    {
        solver          GAMG;      // 代数多重网格
        tolerance       1e-7;
        relTol          0.1;       // 外层迭代时相对容差
    }
    U
    {
        solver          smoothSolver;
        smoother        GaussSeidel;
        tolerance       1e-8;
    }
}
relaxationFactors
{
    equations
    {
        U               0.7;       // 动量欠松弛
        p               0.3;       // 压力欠松弛
    }
}
```

字典写法让算例可版本控制、可批量生成，也让“为什么这个算例不收敛”变成可检索的配置问题。

## 选型建议

- **内流、传热、一般工程**：Fluent 最省心，模型与案例覆盖最广。
- **叶轮机械、旋转部件、共轭传热**：CFX 的交界面与耦合求解更成熟。
- **复杂外流、大规模并行、多面体网格**：STAR-CCM+ 的前处理与自动化占优。
- **多物理场、科研级耦合、自定义方程**：COMSOL 的弱形式接口最直接。
- **需要改源码、批量脚本、预算有限**：OpenFOAM 或 SU2，但要把验证成本算进去。
- **气动外形优化**：SU2 的伴随方法可以一次算例得到全部设计灵敏度，效率远高于有限差分。

商业与开源的真实差别常在“验证成本”。商业软件自带经过大量算例校验的模型与默认设置，出问题时厂商支持可追责；开源软件把自由给了用户，也把验证责任给了用户。用 OpenFOAM 做一个此前没做过的多相算例，往往需要先复现一个实验或基准，时间成本可能超过许可证费用。

:::tip 混合使用
常见做法是用商业软件做前处理与后处理，用 OpenFOAM 做大规模并行求解；或用 Python 脚本批量生成 OpenFOAM 算例，再把结果转成 VTK 用 ParaView 分析。工具之间通过 CGNS、VTK、OpenFOAM 目录交换，不必绑定一家。
:::

## 常见坑

**单位制**。CAD 常用毫米，求解器默认米；导入后尺寸缩小一千倍，雷诺数跟着错三个数量级。STL 没有单位，PLOT3D 可能用英尺，CGNS 可能无量纲。导入后第一件事是量一下特征长度。

**湍流入口**。只给一个湍流强度而不给水力直径或长度尺度，入口耗散率会失真；反过来，给的湍流长度尺度大于流道尺寸也不合理。入口 $k$ 与 $\omega$ 应与目标湍流强度、粘度比一致。

**壁面 $y^+$**。壁面函数要求首层落在对数层，低雷诺数模型要求 $y^+<1$。换模型不换网格，是最常见的“收敛但错误”。

**收敛假象**。残差下降可能是因为松弛因子太小，监测量仍在漂移；也可能是局部区域不收敛，被全局平均掩盖。要看监测量、进出口不平衡与关键截面的剖面。

**后处理变量定义**。总压与静压、表压与绝对压力、总温与静温、运动压力 $p/\rho$ 与压力 $p$，在软件里经常只差一个下拉框。比较两个算例前，先确认变量定义与参考值一致。
