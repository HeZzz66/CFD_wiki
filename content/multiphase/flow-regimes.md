单相流动只有一个速度场，多相流动至少有两个：气相走得快、液相走得慢，界面还在不断变形、破裂与合并。正是这种“相间速度差 + 可变形界面”，让多相流的压降与传热计算比单相复杂一个量级。工程上最实用的切入点不是直接写三维方程，而是先判断**流型**（flow regime）：同一组质量流量与干度，在不同流型下的压降可能相差数倍，传热系数相差一个量级。

这一页先建立描述多相流的共同语言，再分别讨论垂直管与水平管的流型，最后说明流型如何决定后续的建模路线。

## 描述多相流的基本量

### 体积分数与干度

对气液两相流，定义**截面含气率**（void fraction）

$$
\alpha=\frac{A_g}{A},
$$

即管道截面积中被气相占据的比例，液相份额为 $1-\alpha$。与之对应的是**质量含气率**（干度，quality）

$$
x=\frac{\dot m_g}{\dot m_g+\dot m_l},
$$

它是质量流量之比，而不是面积之比。两者通过相速度联系起来，绝不能互换。工程上还常用**体积含气率** $\beta=\dot V_g/(\dot V_g+\dot V_l)$，它与干度的关系为

$$
\beta=\frac{x/\rho_g}{x/\rho_g+(1-x)/\rho_l}.
$$

只有当两相速度相等（均相模型）时才有 $\alpha=\beta$。

### 表观速度

把某一相的质量流量除以**整个管道截面**，得到该相的**表观速度**（superficial velocity）：

$$
j_g=\frac{\dot m_g}{\rho_g A},\qquad
j_l=\frac{\dot m_l}{\rho_l A}.
$$

混合物的表观速度定义为 $j=j_g+j_l$。真实相速度与表观速度的关系是

$$
u_g=\frac{j_g}{\alpha},\qquad
u_l=\frac{j_l}{1-\alpha}.
$$

这两个式子是多相流一维分析的地基：给定 $j_g$、$j_l$ 与 $\alpha$，就能反算出两相真实速度；反之亦然。

### 滑移比

定义滑移比

$$
S=\frac{u_g}{u_l},
$$

则干度、体积分数与滑移比满足

$$
\alpha=\frac{1}{1+\dfrac{1-x}{x}\dfrac{\rho_g}{\rho_l}S}.
$$

$S=1$ 对应均相模型；$S>1$ 表示气相超前。对水-蒸汽系统，$S$ 常在 1.5–5 之间，低压时更大。这条关系说明：**同样的干度，滑移越强，含气率越小**——气相跑得快，意味着同样的质量流量只需要更小的体积份额。反过来，若实验测到 $\alpha$，就可以反推滑移比，这是校验一维模型最直接的手段。

### 界面面积浓度

相间交换（阻力、传热、传质）都正比于界面面积。定义**界面面积浓度**

$$
a_i=\frac{A_i}{V},
$$

单位是 $\mathrm{m^2/m^3}$。对直径为 $d_b$ 的球形气泡群，若体积分数为 $\alpha$，则

$$
a_i=\frac{6\alpha}{d_b}.
$$

非球形气泡用 Sauter 平均直径

$$
d_{32}=\frac{\sum_i n_i d_i^3}{\sum_i n_i d_i^2},
$$

它保持“总面积/总体积”不变。$a_i$ 与 $d_{32}$ 是欧拉-欧拉两流体模型必须封闭的量，也是群体平衡模型（PBM）要求解的对象。

## 垂直上升管中的流型

垂直上升气液两相流是锅炉、沸腾通道与气提塔的典型工况。按含气率由低到高，依次出现四种主要流型。

**泡状流（bubbly flow）**：离散气泡在连续液相中上升，气泡近似球形或椭球形，尺寸多为毫米量级。气泡之间距离较大，相互干扰弱。含气率通常低于 0.25–0.3；超过这一范围气泡开始拥挤、合并。

**弹状流（slug flow）**：小气泡合并成与管径同量级的“Taylor 弹”（Taylor bubble），弹头呈球帽状，弹尾有尾迹；弹与弹之间是含小气泡的液塞（liquid slug）。弹状流是垂直管中最常见的流型之一，压降与管壁剪切呈周期性脉动，管系容易产生振动。

**搅混流（churn flow）**：含气率进一步升高，弹状结构被破坏，气液两相剧烈搅混，界面形状不规则且频繁破裂。它是弹状流向环状流过渡的中间状态，在有些文献中被并入弹状流。

**环状流（annular flow）**：气相在管道核心形成连续气柱，液相被甩到壁面形成液膜，核心中夹带液滴。液膜厚度与卷吸率决定压降与壁面传热；干度接近 1 时进入**雾状流（mist flow）**，液膜消失，只剩气相与离散液滴。

| 流型 | 典型含气率 | 主要特征 | 主导相间作用 |
| --- | --- | --- | --- |
| 泡状流 | $\alpha\lesssim0.25$ | 离散小气泡，近似球形 | 阻力、气泡诱导湍流 |
| 弹状流 | $0.25\lesssim\alpha\lesssim0.6$ | Taylor 弹 + 液塞，周期性强 | 弹头形状阻力、尾迹掺混 |
| 搅混流 | $0.5\lesssim\alpha\lesssim0.8$ | 结构破碎、剧烈振荡 | 界面破裂、携液 |
| 环状流 | $\alpha\gtrsim0.8$ | 气芯 + 液膜 + 液滴 | 液膜剪切、夹带与沉积 |

表中的含气率范围只是数量级参考：管径、物性、压力与入口条件都会移动这些边界，不同教材给出的分界也不完全一致。实际计算应以流型图或实验为准。

### 转变的物理机制

- **泡状流 → 弹状流**：气泡密集到相互碰撞的频率超过合并时间尺度，本质是“气泡拥挤”（bubble crowding）。判据通常写成临界含气率或临界气泡间距。
- **弹状流 → 搅混流**：液塞被气相穿透，弹状结构无法维持；在细管内更容易直接进入搅混。
- **搅混流 → 环状流**：气相惯性足以把液相压向壁面并维持连续气芯，常用气相 Weber 数或无量纲气速判别。
- **液滴夹带**：气芯速度超过临界值时，液膜表面被 Kelvin–Helmholtz 不稳定波撕出液滴。

## 水平管中的流型

水平管中重力垂直于流动方向，因此出现垂直管没有的**分层**现象。常见流型有：

**分层流（stratified flow）**：液相沉在管底，气相在上方，界面平滑（smooth）或出现波动（wavy）。低流速、低含气率时出现，是凝液管线与低负荷冷凝器的典型工况。

**塞状流（plug flow）**：长气泡（气塞）沿管顶间歇通过，气泡之间是液段，界面相对平缓。它与垂直弹状流的区别在于重力使气泡偏向管顶。

**弹状流（slug flow）**：气塞速度增大，前端形成剧烈掺混的液塞，液塞中可能夹带气泡。这是水平管压降脉动与冲蚀最严重的流型之一。

**环状流（annular flow）**：高速气相把液相拉成管壁环状膜，管底液膜较厚、管顶较薄，液膜在周向分布不均匀。

**分散泡状流（dispersed bubble flow）**：液相湍流足够强，把气泡打散并悬移在液相中，近似均相。它出现在高液速、低含气率的工况。

水平管流型的周向不对称性，是三维 CFD 与一维模型拉开差距的主要原因：一维模型只能给截面平均值，而分层、周向液膜厚度、底部积液的传热恶化都必须用二维/三维描述。

## 流型图与转变判据

工程上判断流型有三种做法。

**第一种：经验流型图。** 以表观速度 $j_l$、$j_g$ 为坐标的 Baker、Mandhane 图，或加入物性修正的 Baker 图，直接查图定流型。优点是快，缺点是对新工质与新管径外推能力差。

**第二种：半理论转变判据。** Taitel–Dukler 型模型把每个转变写成力平衡：分层流向波状流由气相对界面的剪切决定，向间歇流由液位升高决定，向环状流由气芯惯性决定。这类判据通常用到 Martinelli 参数

$$
X=\left(\frac{(dp/dz)_l}{(dp/dz)_g}\right)^{1/2},
$$

以及 Froude 数、气相 Weber 数等。它们比查图更有物理依据，但仍是半经验封闭。

**第三种：直接数值判别。** 用 CFD 或界面追踪算出瞬时界面，按几何特征分类。成本高，主要用于研究与方法验证。

常用的无量纲量有：

$$
Fr=\frac{j}{\sqrt{gD}},\qquad
We_g=\frac{\rho_g j_g^2 D}{\sigma},\qquad
Re_l=\frac{\rho_l j_l D}{\mu_l}.
$$

$Fr$ 衡量惯性力与重力之比，$We_g$ 衡量气相惯性力与表面张力之比。前者主导分层与重力效应，后者主导液膜撕裂与液滴生成。

:::note 流型判据的适用边界
所有流型图都建立在特定工质、管径与压力范围内。把水-空气常压数据直接套到高压蒸汽或低温制冷剂上，误差可能很大。工程计算中应优先使用同工质、同压力、同管径的公开数据或关联式，并做敏感性分析。
:::

## 流型对建模路线的影响

流型不仅决定压降与传热，也决定该用哪一类 CFD 模型。

| 流型 | 推荐模型 | 关键封闭量 | 网格要求 |
| --- | --- | --- | --- |
| 泡状流 | 欧拉-欧拉两流体 / 混合模型 | 阻力系数、升力、气泡诱导湍流 | 气泡尺度以下不需要解析，但需足够统计样本 |
| 弹状流 | 界面捕捉（VOF/Level-Set）或弹状流跟踪 | 表面张力、接触角、液膜厚度 | 界面附近 10 层以上网格 |
| 分层/波状流 | 界面捕捉或双流体 + 界面重构 | 界面剪切、波增长 | 界面法向加密 |
| 环状流 | 液膜模型 + 气芯两流体 / 多流体 | 夹带率、液膜动量 | 周向与壁面加密 |
| 分散泡状/雾状 | 欧拉-拉格朗日或 PBM | 破碎/合并核、阻力 | 颗粒统计收敛 |

这张表是后续各页的索引：[[multiphase/homogeneous-drift-flux|均相流与漂移流]] 给出一维快速估算，[[multiphase/two-phase-momentum|两相流动量方程与压降]] 给出分相压降，[[multiphase/multiphase-cfd|多相流 CFD 建模]] 给出三维方法。

## Python 示例：由质量流量估算含气率与流型

下面的脚本按均相假设与滑移关系分别估算含气率，并用 Froude 数、Weber 数给出流型的初步判断。结果只用于数量级估计，正式计算应查流型图或实验数据。

```python
import numpy as np

rho_l, rho_g = 998.0, 1.2      # 水-空气，常压
mu_l, sigma, g = 8.9e-4, 0.072, 9.81
D = 0.05                       # 管径 50 mm
A = np.pi * D**2 / 4

def void_fraction(m_dot, x, S=1.0):
    """由总质量流量与干度计算 alpha；S=1 为均相。"""
    alpha = 1.0 / (1.0 + (1.0 - x) / x * rho_g / rho_l * S)
    j_g = x * m_dot / (rho_g * A)
    j_l = (1.0 - x) * m_dot / (rho_l * A)
    return alpha, j_g, j_l

def classify(j_g, j_l, alpha):
    """极简流型判据，仅作数量级参考。"""
    Fr = (j_g + j_l) / np.sqrt(g * D)
    We = rho_g * j_g**2 * D / sigma
    if alpha < 0.25 and j_l > 0.5:
        return "泡状/分散泡状"
    if alpha < 0.55 and Fr < 3:
        return "弹状/塞状"
    if We > 300:
        return "环状/雾状"
    return "搅混/过渡"

for x in [0.01, 0.05, 0.1, 0.3]:
    for S in [1.0, 3.0]:
        alpha, j_g, j_l = void_fraction(2.0, x, S)   # 2 kg/s
        print(f"x={x:4.2f} S={S:3.1f}  alpha={alpha:5.3f}  "
              f"j_g={j_g:6.3f}  j_l={j_l:6.3f}  流型≈{classify(j_g, j_l, alpha)}")
```

运行后可以直观看到：同一干度下，$S$ 从 1 增大到 3，含气率显著下降；这正是“干度不能代替含气率”的数值证据。

:::warning 一维估算的局限
上式把滑移比当作常数，而真实滑移比随干度、压力与流型连续变化。用它算出的 $\alpha$ 只能作为初值，不能直接用于压降与传热计算。含气率的可靠来源是实验、漂移流关联式或三维 CFD。
:::

## 小结

- 多相流的描述需要四组量：体积分数 $\alpha$、干度 $x$、表观速度 $j_k$、滑移比 $S$。
- 垂直管流型按含气率升高依次为泡状、弹状、搅混、环状；水平管还多出分层与塞状，且周向不对称。
- 流型转变的物理机制是气泡拥挤、弹状结构失稳、气芯惯性压膜与界面不稳定波。
- 流型决定建模路线：分散相用欧拉-欧拉，界面主导用 VOF/Level-Set，液膜主导用膜模型。
- 一维估算可以给出数量级，但不能替代流型图与实验。
