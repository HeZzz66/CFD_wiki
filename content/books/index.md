这里是**书籍区**：教材、软件手册、技术报告与标准文档放在这里，和每周检索到的论文、正在读的文献分开管理。三者用途不同：检索论文追新，书籍查系统推导，在读文献做批注与知识沉淀。

## 支持的文件类型

| 类型 | 扩展名 | 在线阅读方式 |
| --- | --- | --- |
| PDF | `.pdf` | 浏览器内置 PDF 阅读器，可缩放、翻页、全文检索 |
| Word | `.docx` | 上传时自动转换为 HTML（保留标题、段落、表格），在阅读器中直接浏览 |
| 网页 | `.html` / `.htm` | 沙箱 iframe 渲染，外部脚本不会影响主站 |

单文件上限 200 MB。上传时填写标题、作者与年份，列表按上传时间倒序排列。

## 两种存储方式

站点是纯静态的，因此上传行为分两种情况：

- **本地服务模式**：用 `python build.py --serve` 打开。文件写入 `library/files/`，元数据写入 `library/manifest.json`，转换后的 DOCX 预览写入 `library/previews/`。重新构建后依然存在，也可以随站点一起部署。
- **浏览器本地模式**：直接访问 GitHub Pages 或双击 `site/index.html`。文件存入当前浏览器的 IndexedDB，只在本机可见；清理浏览器数据会丢失。

两种模式对使用者是透明的：页面会探测 `/api/library` 是否存在，有服务就走服务端，没有就退回本地存储。

:::tip 建议
需要长期保存的教材与手册请用 `--serve` 模式上传，文件会落在 `library/` 目录里，后续可以直接用 Git 或网盘同步。
:::

## 与在读文献的分工

书籍是“查”的：需要某个公式的推导、某张物性表、某个软件的参数说明时回来翻。
正在读的论文与专著章节请放到[在读文献](../reading/index.html)，那里会保留逐页笔记，并能把要点导入个人知识库，形成可检索的词条与关系图。
