        Tecplot 操作与后处理流程

        从 zone 与 variable 的数据模型出发，讲清 Tecplot 加载各类 CFD 文件、切片、等值面、流线、矢量、XY 曲线、动画、导出与宏批处理，并给出 OpenFOAM 与 FLUENT 的端到端流程。

        后处理与可视化 · 约 2999 字 · #Tecplot#后处理#可视化#宏

        Tecplot 的核心优势不是“画得好看”，而是对多区域、多时间步、结构化与非结构网格的统一管理：一个文件可同时装几十个 zone、上百个变量与完整时间轴，切片、等值面、流线都能直接交互操作。

        按“数据模型—操作—导出—批处理—常见坑—端到端”展开；界面以 Tecplot 360 为准，版本间菜单略有差异。

        数据模型：zone、variable 与 solution time

        数据分三个层次。

        variable（变量）是全局的列，所有 zone 共享同一套定义，顺序在文件头的 VARIABLES 中声明；矢量由多个标量组合而成，例如 U、V、W。

        zone（区域）是一块网格及其上的解，有自己的拓扑、节点数、单元数和变量值；多块网格、不同材料区、旋转域与静止域通常各占一个 zone。

        solution time（解时间）是瞬态数据的第四维。同一 strand 下，不同 zone 可带不同 SOLUTIONTIME，Tecplot 用时间轴串成动画；缺少时间标记的多帧数据只能当作独立 zone。

        一个最小的 ASCII 文件长这样：

        TITLE = "channel flow"
VARIABLES = "X", "Y", "Z", "U", "V", "W", "P"
ZONE T="fluid", N=1200, E=600, DATAPACKING=BLOCK, ZONETYPE=FETETRAHEDRON

        结构化区域用 I、J、K 声明三个方向的节点数，非结构区域用 N（节点）与 E（单元）。DATAPACKING=POINT 表示按点逐行排列所有变量，BLOCK 表示按变量分块排列。单元中心变量需要显式声明：

        VARLOCATION=([7]=CELLCENTERED)

        二进制 .plt 是 Tecplot 的原生格式，读写快、支持多 zone 与多时间步；.szplt 是新版的分块二进制格式，适合超大瞬态数据。ASCII .dat 便于检查与版本管理，但体积大、读入慢。

        先看文件头

        拿到一个陌生文件，先打开前二十行：VARIABLES 顺序、ZONE 拓扑与 DATAPACKING 决定后续操作；二进制文件则在 Data > Data Set Info 核对变量名、范围与 zone 数。

        加载 .plt、.dat 与 .cas/.dat

        Tecplot 的 File > Load Data File(s) 可以按扩展名自动识别大多数格式。

        • .plt、.szplt：直接载入，保留 zone、变量与时间信息。
        • .dat：ASCII 数据，可能是 Tecplot 格式，也可能是其他软件导出的列式数据；后者需手动指定变量列与区域。
        • .cas + .dat：FLUENT 的网格与解。先载入 .cas 建立网格与边界区，再载入同名 .dat 的场数据；顺序反了会丢边界标记。
        • .vtk、.vtu、.cgns：通过通用数据载入器读取，边界条件与参考量通常不在文件里，需要自己补。
        • OpenFOAM 目录：Tecplot 360 自带 OpenFOAM 读取器，选择算例根目录或 case.foam 即可；旧版本可先用 foamToVTK 转成 VTK。

        “扩展名对就能读”是误解。部分 Fluent .dat 把网格与解分开存储；载入后变量列表为空，通常说明只读到了网格。

        切片（slice）

        切片把三维场降到二维。Tecplot 的 Slice 工具支持过三点、指定原点与法向、沿坐标轴等距切多刀三种定位方式。

        操作要点：

        1. 在 Slice 对话框中选 Slice through volume，设定平面。
        2. 勾选 Show surface 先预览，确认没有切到实体内部或空白区。
        3. 需要定量分析时点 Extract，把切片转成新 zone；只有提取后，变量才能参与积分、导出与 XY 提取。
        4. 多刀切片用 Group 管理，统一色标。

        切片是插值结果：非结构网格上，Tecplot 用单元与平面的交线重建多边形，单元中心变量先插值到节点。壁面附近的薄切片，这个误差可能比要看的现象还大。

        等值面（isosurface）

        等值面是某个变量取定值的曲面，用来显示涡结构、激波面、燃烧前锋或浓度界面。

        在 Iso-Surface 对话框中选定变量与等值，例如用 Q 准则取 \(Q=0.1\) 显示涡管，或用压力取 \(p/p_\infty=0.5\) 显示激波。Extract 后可对曲面做面积、通量积分；不提取则只是显示层。Iso-blank 可遮掉等值面一侧的体数据，多值等值面适合展示随时间演化的激波。等值面质量受网格限制；粗网格上的块状折面应在网格上解决，用平滑只会移动等值面的真实位置。

        流线（streamtrace）

        流线沿着速度场积分，显示流动的走向。Tecplot 的 Streamtrace 工具需要先指定矢量变量（通常是 U、V、W），再选择种子类型：

        种子类型 用途 注意
        Line 在一条线段上均匀布点 适合二维切片或入口截面
        Rake 沿一条空间直线布点 三维外流最常用
        Sphere 在球面上布点 观察分离涡、回流区
        Volume 在体积内随机布点 看整体拓扑，但图容易乱

        积分参数包括步长、最大步数、积分方向与终止条件。步长太大，流线会穿过壁面或跳过小涡；太小则计算慢且线条抖动，建议先粗后细。Tecplot 提供 Euler 与 Runge-Kutta 4；默认 RK4 在光滑流场中更准，壁面附近仍需配合 Termination 的边界与速度阈值。

        流线不是迹线

        定常流中流线与迹线重合；非定常流中它们一般不同。用瞬态数据做流线时，Tecplot 默认在某一时刻的瞬时速度场上积分，得到的是“瞬时流线”，不能直接解释为示踪粒子的运动轨迹。要看粒子轨迹，应使用 Particle Trace 或求解器输出的 Lagrangian 数据。

        矢量图

        矢量图把速度、涡量或自定义矢量画成箭头。Vector 图层的关键参数是矢量类型、长度缩放与箭头稀疏度。

        • Vector Type 选 Velocity 时长度按速度模长缩放；选 Vorticity 时箭头方向表示旋转轴，长度表示涡量大小。
        • Length 默认常让箭头过密，建议先减到三分之一再调。
        • Sparseness 控制箭头间隔，三维图尤其需要稀疏。

        矢量图适合看方向，不适合看大小；长度缩放会破坏数值可比性。

        XY 曲线

        XY 曲线用于把沿一条线的量画成二维图，例如壁面压力分布、边界层速度剖面、出口总压损失。

        流程是：Data > Extract > Polyline 沿指定线段取样，生成新 zone；再用 Plot > XY Line 把它设为数据源。常用设置包括：手动固定轴范围，避免不同工况自动缩放；边界层剖面用 \(u^+\) 对 \(y^+\) 时开对数纵轴；实验点用符号、计算用实线；图例写明工况与雷诺数。沿线取样步长决定曲线是否漏掉峰值，激波处的步长应小于当地网格尺度。

        多帧动画

        瞬态数据按 SOLUTIONTIME 排序；Animate 对话框可设起止时间、帧间隔与循环方式，并导出 AVI 或 GIF。

        要让动画正确，必须保证：

        1. 每个时间步的 zone 都带 SOLUTIONTIME，且时间单调。
        2. 所有时间步的变量名与 zone 名一致；改名会导致某些帧找不到变量。
        3. 色标范围固定。自动范围会让每帧颜色含义变化，动画看起来在“闪”。
        4. 切片位置固定，否则观众无法区分“结构演化”与“切片移动”。

        如果数据按文件名排序（如 flow_1.plt、flow_2.plt、flow_10.plt），字典序会把 10 排在 2 前面。正确做法是写成一个多时间步的 .plt，或在宏里按数值顺序载入。

        导出图片与数据

        File > Export 支持图片与数据两类输出。

        图片常用 PNG、TIFF 与 EMF：PNG 适合网页，TIFF 适合期刊，EMF 是矢量格式。分辨率按最终尺寸设定，8 cm 宽、300 dpi 约需 945 像素，直接导出 2400 像素更稳妥；同时手动设定宽高比、打开抗锯齿，并把色标与图例一起导出。

        数据可导出为 Tecplot ASCII、CSV 或二进制。先把切片或等值面 Extract 成 zone，再 File > Export > ASCII，只选需要的变量；CSV 列名与变量名一致，便于 Python 复核。

        宏与批处理

        Tecplot 的所有界面操作都可以录制成宏。Scripting > Record Macro 开始录制，操作一遍后停止，保存为 .mcr。宏是一串 $! 命令，可以手改参数，也可以循环执行。

        批处理调用：

        tecplot -b -m postprocess.mcr

        -b 为批处理模式，-m 指定宏。Windows 下可执行文件可能是 tecplot.exe，路径要写全；先在单算例上跑通，确认输出目录存在、文件名不含中文与空格。

        一个可运行的宏骨架如下（切片等命令由录制生成，参数名随版本略有差异）：

        #!MC 1410
$!ReadDataSet 'E:/case/flow.plt'
$!ExportSetup
  ExportFormat = PNG
  ImageWidth = 2400
  ImageHeight = 1600
$!Export
  ExportDestination = 'E:/case/cp.png'

        宏的价值在于可复现：同一套切片位置、色标与导出尺寸可批量套用几十个工况。把宏与算例清单放进版本库，比手工点几十次可靠。Tecplot 也提供需额外授权的 PyTecplot，可与 numpy 交换数组；批量出图时宏通常更简单。

        常见坑

        单位。 Tecplot 不做换算。Fluent 导入的可能是表压，OpenFOAM 不可压缩的 p 是运动压力（单位 \(\mathrm{m^2/s^2}\)），都不能直接与实验的 Pa 比较。先看数量级：室温空气绕流的动压约一百帕；压力显示 \(10^5\) 则是绝对压力。

        zone 顺序。 瞬态多 zone 的顺序由 SOLUTIONTIME 决定，不由 zone 编号决定。手工拼接文件时，如果时间列缺失，动画会按 zone 顺序播放，看起来像“时间倒流”。

        变量名大小写。 表达式区分大小写，{P} 与 {p} 是两个变量；名称含空格时用花括号包住，例如 {Velocity X}。导入后先在 Data > Data Set Info 核对实际名称，再写公式。

        空白值。 Tecplot 用 \(1.0\times10^{30}\) 表示空白，NaN 不一定会被识别；处理不当会让等值面出现大片缺口。

        点数据与单元数据。 压力常存在单元中心，而等值线需要节点值；直接画会得到块状阶梯，应先 Data > Interpolate > Node Values 或明确接受单元中心显示。

        二维与三维。 二维数据如果写成三维 zone 且 Z 全为零，切片法向选 Z 会得到整个面；选 X 或 Y 则得到一条线。先确认 Plot > Axis 的维度设置。

        端到端流程：从求解器结果到成图

        OpenFOAM

        1. 求解器写出 0/、0.1/、0.2/ 等时间目录，先确认 constant/polyMesh 完整。
        2. 转换或直接读取：

        text foamToVTK -latestTime

        输出在 VTK/ 下，也可让 Tecplot 直接读算例根目录。 3. 载入后核对 zone 数与变量名。不可压缩算例的 p 是运动压力，量纲为 \(\mathrm{m^2/s^2}\)。 4. 在 Data > Alter > Specify Equations 中写：

        text {Cp} = ({p} - {p_inf}) / (0.5 * {U_inf}**2)

        {p_inf} 与 {U_inf} 可建成常量变量，也可在公式里直接写数值。 5. Z 方向取中截面并 Extract 成 zone，画 Cp 等值线，色标固定为 \(-3\) 到 \(1\)。 6. 入口前布置 Rake 种子画流线，用 Sphere 种子观察分离区。 7. 导出 PNG（2400 像素宽）与切片 CSV，后者交给 Python 复核积分量。

        FLUENT

        1. File > Load Data File(s) > FLUENT，先 .cas 后 .dat。
        2. 在 Data > Data Set Info 确认压力单位与参考值。若 Operating Pressure 非零，导入的可能是表压，需加回操作压力。
        3. 用同一组参考量计算 Cp：

        text {Cp} = ({Pressure} - {p_inf}) / (0.5 * {rho_inf} * {U_inf}**2)

        1. 切片、等值面、流线的操作与 OpenFOAM 相同，区别只在变量名与单位。
        2. 壁面压力用 Extract > Polyline 沿翼型取样，再画 XY 曲线与实验对比；批量工况用宏循环。
        先做一张“体检图”

        每个算例先出三张图：中截面压力云图、壁面 \(y^+\) 分布、入口与出口流量对比。这三张图能发现大多数设置错误，成本却很低。确认无误后，再花时间做漂亮的等值面与动画。
