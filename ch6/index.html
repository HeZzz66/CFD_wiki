        CHAPTER 8 Tecplot · Python · 场数据可视化

        本章导览

        后处理把求解器输出的网格与场数据变成可判断的图表与指标：本章覆盖 Tecplot 操作、Python 读写、核心算法实现与出版级出图。

        后处理与可视化 · 约 1586 字 · #后处理#可视化#学习路径

        计算收敛、残差下降，只是得到了一堆数字。要判断结果对不对、好不好，必须把数字重新变成空间分布、曲线与积分量，这一步就是后处理。它既是 CFD 工作流的最后一环，也是最容易被低估的一环：同一个算例，后处理方式不同，可能得出相反的结论。

        后处理在 CFD 工作流中的位置

        一次完整的 CFD 分析可以分为三段：

        flowchart LR
    A["几何与网格"] --> B["求解器迭代"]
    B --> C["场数据与日志"]
    C --> D["读取与检查"]
    D --> E["派生量与积分量"]
    E --> F["图表与报告"]

        前处理决定“算得准不准”，求解决定“算得对不对”，后处理决定“看不看得懂”。三者并不独立：后处理阶段发现的异常，常常要回到网格或边界条件去修。壁面 \(y^+\) 分布显示第一层网格落在缓冲层，说明网格或湍流模型需要调整；出口与入口的质量流量相差百分之几，说明计算还没有真正守恒。

        后处理可以拆成三个层次。

        数据层解决“读得进”。要弄清文件里有哪些区域、哪些变量、单位是什么、时间步如何组织、数据在点上还是在单元中心。多数“打不开”或“云图乱掉”的问题出在这一层，而不是可视化算法。

        指标层解决“算得对”。把原始场换算成有物理意义的量：压力系数、摩擦系数、涡识别判据、流量、阻力。每一步都涉及参考量与符号约定，错一个基准值，整张图就失去意义。

        表达层解决“画得清”。选坐标范围、色标、视角与图幅，让读者在十秒内抓住主要结构，同时保留可核查的细节。

        参考量先行

        动压 \(q_\infty=\tfrac12\rho_\infty U_\infty^2\) 是无量纲化的共同分母。压力系数、摩擦系数、升阻力系数都建立在同一组参考量上。开始画图前，先把 \((\rho_\infty, U_\infty, L_{\mathrm{ref}}, A_{\mathrm{ref}})\) 写进脚本注释，后面所有图都用这一组值。

        建议阅读顺序

        如果你手上已经有一个算例，只是想把结果画出来，可以先读 Tecplot 操作，照着端到端流程走一遍；遇到文件读不进去，再查 Python 读写 的格式对照。两条路线不是替代关系：Tecplot 适合交互探索与快速出图，Python 适合批量处理与可复现的指标计算。

        如果你要写论文或做对比研究，建议按 Python 读写、核心算法、出版级出图 的顺序读。先保证数据读对，再保证指标算对，最后才谈图好不好看。反过来先调图，往往是在给错误的数上色。

        Tecplot 与 出图 两页可以穿插读：Tecplot 里的切片、等值面、流线概念，在 PyVista 中有几乎一一对应的函数；反过来，Python 的色标与版式规范也可以带回 Tecplot。

        与前五章的衔接

        后处理不是孤立技能，它把前面几章的概念变成可测量的量。

        • 场论 给出梯度、散度、旋度，这是涡量、Q 准则与流线积分的基础。
        • 量纲分析 解释了为什么用动压与参考长度做无量纲化，以及 Cp、Cf 为什么无量纲。
        • 边界层 给出壁面剪切、y+ 与对数律，是判断网格是否合适、摩擦阻力是否可信的依据。
        • 控制方程 提供守恒检查：入口与出口的质量、动量、能量收支应当闭合。
        • 数据格式 解释 .plt、.dat、.cas、.vtu、.cgns 的组织方式，决定你用什么工具读。
        • RANS 与 LES 决定后处理该统计什么：时均量、雷诺应力、湍动能谱。
        • 数据集与评价 提供误差指标与基准算例，可用于校准自己的后处理脚本。

        一条验收清单

        在把图发给别人之前，至少过一遍下面五项：

        1. 网格闭合：体网格单元数、面数、边界标记与求解器日志一致；切片与等值面没有空洞。
        2. 单位一致：压力是表压还是绝对压力、动力黏度还是运动黏度、温度是 K 还是 ℃，逐项核对。
        3. 参考量一致：所有系数用同一组 \((\rho_\infty, U_\infty, L_{\mathrm{ref}}, A_{\mathrm{ref}})\)，并在图注中写明。
        4. 守恒闭合：入口与出口的质量流量、动量通量之差在可接受范围；不闭合就先别解释流场。
        5. 图可复核：色标有单位、坐标有方向、切片位置有标注、脚本与数据版本可追溯。
        常见误区

        “云图漂亮”不等于“结果正确”。平滑的彩色图可能掩盖负压、回流或越界值。先看最小值、最大值与积分量，再看颜色；必要时用等值线而不是填色，避免插值把间断抹平。

        本章不涉及的内容

        网格生成、求解器配置、湍流模型推导在前几章已经讨论；本章只处理“已有网格与场数据之后”的工作。商业软件的授权、安装与界面差异也不展开，操作名称以 Tecplot 360 与 PyVista 的通用版本为准，具体菜单可能随版本调整。
