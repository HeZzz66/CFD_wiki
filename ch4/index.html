    CHAPTER 4 DNS · LES · RANS · 多语言实现

    本章导览

    湍流是多尺度、非线性、非定常的；DNS、LES、RANS 三条路线分别对应“全解析”“大尺度解析 + 小尺度模化”“全部模化”，本章按“统计—模型—实现”的顺序展开。

    湍流模型 · 约 1961 字 · #湍流模型#学习路径#DNS#LES#RANS

    湍流不是一个可以单独开关的“流动状态”，而是 N-S 方程在惯性效应足够强时的普遍解。只要雷诺数超过临界值，扰动就会被对流项不断放大、折叠，最终形成一个从几何尺度一直铺到粘性尺度的连续谱。工程 CFD 中遇到的绝大多数“算不准”，追根溯源都落在同一个问题上：这个谱系里，哪一段被解析、哪一段被模化。

    本章不重复 N-S 方程的推导，而是假设读者已经熟悉守恒方程与有限体积离散。我们从湍流的统计描述入手，再依次介绍 RANS、LES、DNS 的数学结构与代码实现，最后讨论 C++ 与 Fortran 中的工程细节。写法上偏向“公式—代码”对照：每个模型都给出方程、常数与可运行的片段，读者可以抄下来改参数，观察它在哪里失效。

    湍流为什么难

    多尺度。最大的含能涡尺度由几何边界决定，记为 \(L\)；最小的耗散尺度由粘性决定，记为 \(\eta\)。二者之比随雷诺数增长：

    \[\frac{L}{\eta}\sim Re^{3/4},\qquad Re=\frac{U L}{\nu},\]

    其中 \(U\) 是特征速度，\(\nu\) 是运动粘度。若要在三维空间里解析到 \(\eta\)，网格数至少按立方增长：

    \[N_{\mathrm{DNS}}\sim\left(\frac{L}{\eta}\right)^{3}\sim Re^{9/4}.\]

    这意味着 \(Re\) 翻一倍，网格量增加约 5.2 倍。航空整机的 \(Re\) 在 \(10^{7}\) 量级，直接解析所需的网格已经超出任何现有计算机的能力。

    具体一点：若 \(L=1\,\mathrm{m}\)、\(U=10\,\mathrm{m/s}\)、\(Re=10^{6}\)，则 \(L/\eta\approx Re^{3/4}\approx5.6\times10^{3}\)，\(\eta\approx0.18\,\mathrm{mm}\)。按 \(\Delta x=2\eta\) 估计，三维网格约 \((5.6\times10^{3}/2)^3\approx2\times10^{10}\)；即使每核每秒处理 \(10^{5}\) 个单元，单步也要数万核秒，而统计收敛需要 \(10^{5}\) 步以上。这组数字足以说明 DNS 为何只用于研究。

    非线性。对流项 \(u_j\partial u_i/\partial x_j\) 把不同波数的模态耦合在一起，使得各尺度之间不能线性叠加：大涡的破碎会产生小涡，小涡的合并又会影响大涡。这也是“湍流模型”必须引入闭合假设的根本原因。

    非定常。湍流脉动在宽频带上分布，最小的时间尺度是 Kolmogorov 时间 \(\tau_\eta\)。若用显式时间推进，时间步长受 \(\tau_\eta\) 与 CFL 条件共同限制，进一步放大了成本。

    三条路线的分层逻辑

    三条路线可以用“在能谱 \(E(k)\) 的哪个波数处切断”来理解。DNS 把截止波数推到耗散区，所有尺度都被解析；LES 把截止放在惯性区，只模化亚格子部分；RANS 把截止压到 \(k=0\)，全部脉动都被平均掉。

    \[k_{\mathrm{cut}}= \begin{cases} k_{\max}, & \text{DNS}\\[2pt] \pi/\Delta, & \text{LES}\\[2pt] 0, & \text{RANS} \end{cases}\]

    在这条谱线上，越往右解析越多、模型越少、成本越高。工程选型的本质，是在“可接受的误差”与“可承担的网格量”之间找平衡点。现实中的方案常常是混合的：DES/DDES、PANS 以及数据驱动的亚格子模型，都可以理解为在谱线上移动截止波数的尝试。

    方法 解析尺度 需要模化的量 典型网格量 相对成本 适用场景
    DNS 全部，含耗散尺度 \(\eta\) 无（只依赖格式精度） \(Re^{9/4}\)，\(Re=10^4\) 时约 \(10^{9}\) 极高 机理研究、模型标定、小尺度算例
    LES 大于滤波尺度 \(\Delta\) 的涡 亚格子应力 \(\tau_{ij}\) 约 \((L/\Delta)^3\)，常为 \(10^{6}\sim10^{7}\) 高 分离流、燃烧、气动噪声、大尺度非定常
    RANS 仅平均场 全部雷诺应力 \(10^{4}\sim10^{6}\) 低 工程定型设计、参数扫描、稳态问题
    成本的粗略换算

    以 \(Re=10^{4}\) 的平板为例，DNS 约需 \(10^{9}\) 网格、LES 约需 \(10^{6}\sim10^{7}\) 网格，二者相差两到三个数量级。RANS 往往只需要 \(10^{5}\) 量级，因此能在工作站上完成整机计算。

    选型：误差预算

    工程上真正要回答的是“这套网格和这个模型，误差大概多少”。把总误差粗略分解：

    \[\epsilon_{\mathrm{total}} \approx\epsilon_{\mathrm{model}} +\epsilon_{\mathrm{discretization}} +\epsilon_{\mathrm{statistics}},\]

    三项分别来自模型假设、离散格式与采样不足。它们的量级并不总是此消彼长：在附着流中，SST 的模型误差通常在 10%～20%，而 LES 若网格不足，离散误差可能超过 50%；反过来，在强分离流中，RANS 的模型误差可以主导一切，此时增加网格几乎无用。因此“换更贵的模型”不一定提升精度，先判断误差主要来自哪一项才是正确顺序。

    经验上的分工是：

    • RANS 用于参数扫描与定型设计，重点保证边界条件、壁面处理与网格无关性；
    • LES 用于复核关键工况（分离、脉动载荷、噪声），重点保证 \(\Delta\) 落在惯性区、近壁 \(y^+\) 达标；
    • DNS 只用于机理研究与模型标定，不参与工程设计循环。

    另一条常被忽略的约束是一致性：模型、壁面处理与网格必须配套。用壁面函数却把首层网格加密到 \(y^+<1\)，或用低 Re 模型却让首层落在对数律区，都会得到比“选错模型”更离谱的结果。

    阅读顺序

    本章按“先物理、再模型、后实现”组织，建议顺序阅读：

    1. 湍流统计与能量级串：先把雷诺分解、湍动能、耗散率、能谱这些“公共语言”建立起来，后面所有模型都在这套符号里表述。
    2. RANS 与涡粘模型：从平均方程出发，看 \(-\rho\langle u_i'u_j'\rangle\) 这一项如何变成涡粘假设，并给出 k-ε、k-ω、SST 的完整方程与 Python 推进代码。
    3. 大涡模拟 LES：把“平均”换成“滤波”，得到亚格子应力；重点掌握 Smagorinsky、动态模型与 WALE 三种闭合。
    4. DNS 与 fDNS：理解分辨率标度律、高精度格式与伪谱法，以及 fDNS 作为“数据生成器”的用途。
    5. C++ 与 Fortran 实现：把公式落到数组与循环上，讨论内存布局、OpenMP 与向量化。

    前置知识

    • 守恒方程与应力张量：至少能读懂 N-S 方程 的每一项，知道 \(\partial u_i/\partial x_j\) 的指标含义；若不熟悉指标记法，可回看 张量分析。
    • 有限体积离散：本章的模型方程都是输运方程，其离散与 有限体积法 中的对流—扩散格式完全同构。
    • 后处理：湍流统计量（时均、脉动、RMS）的提取方法见 后处理。

    读完之后不需要记住每个常数，但要能回答三个问题：这个模型假设了什么、它在什么流动下会失效、代码里每一项对应哪个数组。

    三个常见误区

    • 把 RANS 等同于稳态。RANS 也能做非定常（URANS），但它只解析大尺度的非定常运动，湍流脉动仍被平均掉，因此不能用于声学或高频载荷。
    • 把 LES 等同于“无模型”。LES 必须有亚格子模型，否则网格截断处的能量无处可去，会在高波数端堆积并污染大尺度。
    • 把 DNS 当成“更贵的 RANS”。DNS 的成本随 \(Re\) 超线性增长，网格加密一倍，三维成本增加约八倍，不能靠“多买机器”线性扩展。
    • 把“网格无关”当成“模型无关”。网格收敛只说明离散误差变小，模型误差不会因此消失；反过来，模型对了但网格不足，结果仍可能不可信。
